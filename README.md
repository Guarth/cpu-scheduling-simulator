# cpu-scheduling-simulator
Simulation and analysis of CPU scheduling algorithms to evaluate performance metrics such as waiting time, turnaround time, and CPU utilization.

Overview

This project implements and analyzes multiple CPU scheduling algorithms to understand how operating systems manage process execution and optimize performance.

⚙️ Features
Implemented scheduling algorithms:
First Come First Serve (FCFS)
Shortest Job First (SJF)
Round Robin (RR)
(Add others if you used them)
Simulated process execution with configurable inputs
Computed key performance metrics:
Waiting Time
Turnaround Time
Response Time
CPU Utilization
Compared algorithm efficiency under different workloads
📊 Key Insights
Demonstrated trade-offs between fairness and efficiency
Showed how time quantum impacts Round Robin performance
Highlighted differences in average waiting time across algorithms
